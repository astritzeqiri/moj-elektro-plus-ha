## Prior work: frlequ/homeassistant-mojelektro (MIT)

The existing community integration
<https://github.com/frlequ/homeassistant-mojelektro>
(MIT License, Copyright (c) 2024 frlequ) was read for context: how users
create tokens, what the meter identifier looks like, and which registers
exist. **No source code from it is included in this repository.** Moj
Elektro Plus uses a separate domain (`mojelektro_plus`) so both can be
installed side by side.

Behaviour that this integration handles differently, found while reading the
old code (not a judgement on its usefulness):

* it polled every 30 seconds and indexed the day by local wall-clock time,
  which assumes 96 intervals per day (DST days have 92 or 100);
* missing data was reported as `0.0`;
* errors were logged and returned as `None`, so authentication failures did
  not trigger re-authentication;
* it had no long-term statistics import.
