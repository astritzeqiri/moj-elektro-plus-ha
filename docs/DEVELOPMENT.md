# Development

## Layout

```
custom_components/mojelektro_plus/   everything Home Assistant loads (HACS package)
  api.py          async API client (timeouts, retries, Retry-After, error mapping)
  timeutil.py     UTC identity, Europe/Ljubljana days/months, DST, batches
  data.py         interval storage (UTC-day chunks), merge/dedupe, totals
  storage.py      versioned persistent store (homeassistant.helpers.storage)
  coordinator.py  refresh, background backfill, range refresh, snapshot
  statistics.py   external statistics for the Energy dashboard
  views.py        server-side aggregation and CSV
  websocket.py    authenticated commands used by the sidebar page
  panel.py        shared panel registration
  frontend/       BUILT panel bundle (generated, committed)
  brand/          icons (generated by branding/generate_icons.py)
frontend/          panel source, tests and build script
tests/             pytest suite with a fake API (no network)
script/            docker test runner and dev Home Assistant helpers
```

## Python tests

The tests run on Linux Python 3.14 with
`pytest-homeassistant-custom-component` (pinned in `requirements_test.txt`).
With Docker:

```sh
script/docker-test pytest -q
script/docker-test ruff check .
script/docker-test ruff format --check .
```

Or in any Python 3.14 virtualenv: `pip install -r requirements_test.txt && pytest -q`.

The real Moj Elektro API is never called: `tests/fake_api.py` reproduces the
confirmed behaviour (required ReadingType option, 35-day and two-year limits,
exclusive `endTime`, interval-end timestamps with local offsets, quality
flags, missing values).

## Frontend

```sh
cd frontend
npm ci
npm test          # vitest + happy-dom
npm run build     # writes custom_components/mojelektro_plus/frontend/mojelektro-panel.js
npm run check     # fails if the committed bundle differs from a fresh build
```

The bundle is committed because HACS users do not run Node. Always rebuild
and commit it together with source changes; CI checks they match.

## Local Home Assistant (development only)

```sh
script/dev-ha start      # http://127.0.0.1:18124
script/dev-ha logs
script/dev-ha stop
```

This runs its own container (`mojelektro-plus-homeassistant`) with config in
the ignored `.local/` directory and the integration mounted read-only. By
default it talks to the **real** Moj Elektro API, so you can add your own
token in the UI.

For work without a token, `MOJELEKTRO_DEV_FAKE=1 script/dev-ha recreate`
additionally mounts `script/dev/mojelektro_dev_fake`, a development-only
helper that replaces the HTTP layer with synthetic readings (any token works
except `invalid`; meters `4-93571` with export and `9-12345`). Delete any
synthetic entries before switching back with `script/dev-ha recreate`, so
test data never mixes with real data. Never install that helper in a real
Home Assistant, and never point the dev instance at a production one.
